# DexBotX Economy: Final Sync and Production Readiness Prompt

> Current behavior override: this prompt is a readiness checklist, not evidence that every requested audit or test has run. Economy is opt-in; channels are public, regular member messages are blocked, and slash commands work only in `economy-commands`. Successful daily claims are announced persistently there. Private economy interaction replies expire after 60 seconds. Currency is fixed to Dex. The dashboard manages safe custom purchasable roles only, not built-in items or economy tuning. Robberies are available anytime, require one Robbingusertool per success, and have no active steal-window scheduler; legacy window records are cleanup-only.

## After Copilot finishes

2. Do the manual pass with your own account in the test server. Check the new buyable steal items by hand, the pinned messages, the buttons, and that `/economy pause` works only for an Administrator.
